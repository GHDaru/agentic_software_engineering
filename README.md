# Livro — Engenharia de Software Orientada por Agentes

Bounded context próprio, separado do método Maestro (`../410_MAESTRO`). O Maestro é o objeto de
estudo do livro; o livro não mora no repositório do método.

| Pasta | O que é |
|---|---|
| `livro/` | o livro novo (vazio: a estrutura é a primeira tarefa) |
| `maestro-handbook/` | cópia do livro do método Maestro em 01/11/2026 — `handbook/` (13 capítulos e apêndices), `receitas/`, `diagramas/`, `publicar/` (o build); `ORIGEM.txt` diz o commit |
| `pesquisa/` | a base de pesquisa e, depois, protocolo, runs e `CLAIMS.md` |
| `PROMPT-RESTAURAR.md` | o prompt para abrir uma sessão nova com todo o contexto |

O livro do método ainda existe no Maestro; a retirada de lá é um ciclo próprio (ver o fim do
prompt de restauração).
