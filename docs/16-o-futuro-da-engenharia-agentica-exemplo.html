Um script, futuro.py, em Python 3 (3.8 ou mais novo), sem dependência externa. Os dados estão em dados/:

Arquivo O que é Fonte

Como rodar #

Da raiz do livro:

python livro/16-o-futuro-da-engenharia-agentica/exemplo/futuro.py demo

Outros comandos:

python futuro.py sensibilidade A3 A4                      # cenário: quais regras perdem apoio
python futuro.py gatilhos ESTADO.jsonl EVENTOS.jsonl      # sai 1 se algum gatilho disparou sem reavaliação
python futuro.py calendario 2027-12-02                    # o que do AI Act vale nessa data (sai 1 se o dado venceu)

Códigos de saída: 0 = conforme · 1 = achado · 2 = erro de uso.

O que o "OK" prova, e o que não prova #

As partes 1 e 3 conferem a coerência do script com os próprios dados: axiomas.json foi copiado à mão de axioms.md, e ai-act.json foi digitado a partir do Jornal Oficial. Um erro de cópia passa verde. A parte 2 é a única independente, porque lê o índice real do catálogo. O que a parte 3 acrescenta de não circular é o frescor: o dado carrega conferido_em e validade_dias, e o script recusa responder (sai 1) quando a data consultada passou da validade. Isso não prova que as datas estão certas; obriga alguém a reconferi-las.
