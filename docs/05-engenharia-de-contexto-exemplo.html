Exemplo do capítulo 5 — as quatro operações do contexto, medidas #

O que este exemplo prova, em doze passos, num projeto de brinquedo (uma loja que ganha cupom de desconto no ciclo 007):

  • Seleção — uma tarefa cortada pela fronteira carrega 10% do repositório; a tarefa que atravessa o código inteiro carrega 82%, e essa economia baixa é sinal de corte errado, não de janela pequena. A tarefa que não cita nada manda o executor procurar o contexto sozinho.
  • Compressão — quando a janela compacta e só fica o tasks.md que o executor segue, o que morava na spec e na conversa (revisão independente, segurança, gate humano) é apagado, não degradado. Escritos como token no tasks.md, os mesmos fatos sobrevivem.
  • Persistência — um índice de decisões só-acréscimo: o script recusa id repetido e registro que aponta para um marcador, e um comparador acusa a linha reescrita.
  • Transferência — CLAUDE.md e AGENTS.md escritos à mão divergem do disco (uma skill invisível nas duas, a regra "skills primeiro" ausente numa). Com fonte única e o bloco de skills gerado do disco, a deriva fica impossível.
  • Rastreabilidade — do gate até o porquê em quatro saltos (índice → commit → ciclo → ADR), e o commit sem citação que só a memória de alguém explica.
  • O quadro — as quatro operações do ciclo numa tela: o que um comando de inspeção de contexto mostraria.

Requisito: Python 3.8+ (só biblioteca padrão) e bash. Nada pago, nada de rede.

Como rodar #

cd livro/05-engenharia-de-contexto/exemplo
bash rodar.sh                               # imprime a saída
bash rodar.sh | diff - saida-esperada.txt   # confere: nenhuma linha de diferença

No Windows, rode no Git Bash. O script procura python3, python e py, nessa ordem, e usa o primeiro que for Python 3.8+. Para forçar: PYTHON=... bash rodar.sh. Nada em projeto/ é alterado: o registro de decisão (passos 6–8) roda numa cópia do índice, e a correção da instrução (passo 10) roda numa cópia temporária do projeto. Na correção, AGENTS.md vira link simbólico para CLAUDE.md; sem permissão de link simbólico (Windows comum), vira cópia gerada do mesmo conteúdo, e a conferência é a mesma: igualdade de conteúdo.

Cada subcomando também roda sozinho; python contexto.py sem argumento imprime a ajuda.

Os arquivos #

Arquivo Papel
contexto.py os subcomandos selecionar, compactar, registrar, historico, transferir, rastrear, inspecionar
rodar.sh os doze passos, em ordem
saida-esperada.txt a saída de bash rodar.sh, conferida em 02/11/2026
projeto/CLAUDE.md, projeto/AGENTS.md a instrução para a IA, em duas cópias escritas à mão que já divergiram
projeto/skills/*/SKILL.md três skills no disco; uma (jornada-viva) não aparece em instrução nenhuma
projeto/specs/007-cupom-de-desconto/ spec (com invariantes e o fechamento do ciclo), plano, tarefas e relatório
projeto/src/*.py o código: seis módulos de tamanhos diferentes, gerados para o exemplo
projeto/registros/decisoes.jsonl o índice de decisões só-acréscimo (três linhas)
projeto/registros/commits.txt o assunto de quatro commits, no formato git log --format='%h %s'
projeto/docs/adr/0003-cupom-nao-acumula.md o porquê de uma regra de negócio
casos/conversa.md o que existiu só na janela de contexto, e não em artefato
casos/tasks-com-cauda.md o tasks.md reescrito: T3 autossuficiente, T4 fora (vira outro ciclo), cauda como token TAIL:
casos/decisoes-reescrito.jsonl o índice com a linha 2 editada (de "aberta" para "fechada")

A régua de tokens é estimada (caracteres ÷ 4, arredondado para cima) e está declarada no código. Serve para a razão selecionado ÷ total, não para prever a fatura de um modelo.
